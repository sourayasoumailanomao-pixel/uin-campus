# UIN-Campus

Système de gestion académique de l'UIN (projet fil rouge du cours de POO en C++).

## Versions des outils (Kali Linux dans VMware)

- g++-14 : 14.4.0
- clang : 21.1.8
- cmake : 4.3.4
- ninja : 1.13.2
- gdb : 18.1
- git : 2.53.0

## Construire et exécuter

    cmake --preset debug
    cmake --build --preset debug
    ./build/debug/uin-campus
